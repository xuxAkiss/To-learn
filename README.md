# KIXU LEARN

一个部署在 GitHub Pages 的个人双线学习计划、学习诊断与每日打卡应用。

当前目标：

- 参加 2027 年底初试，暂以复旦计算机类专硕为冲刺目标；
- 在 2027 年 6 月底前完成一个能独立讲清、可评测的后端／AI 应用项目，形成相关实习与就业的基本竞争力。

线上地址：<https://xuxakiss.github.io/To-learn/>

## 功能

- 近期四周详细任务，包含执行步骤、预计用时、完成标准和学习入口
- 周任务与每日打卡分离；每天保留专注计时、学习笔记和打卡记录
- 支持补充自定义周任务，任务包按月根据真实完成情况更新
- “复制本周任务给 AI”：预览所选周任务、链接与进度，个人笔记和复盘默认不包含
- 15 / 25 / 45 / 60 分钟专注计时与周投入统计
- 2026.09—2027.12 的数学、408、后端／AI 应用、英语／政治、求职／报考路线图
- 数学、408、Java 算法、后端／AI 应用项目、英语和双线负荷六类诊断卡
- 周复盘、JSON 导入导出、离线访问和手机端布局

## 当前任务包

- **2026-09-21—09-27：**确认考研与就业双目标、配置 Java/Git、固定资料和时段，约 4 小时
- **2026-09-28—10-25：**连续四周共同基础任务，每周 24 小时；第 1、3 周从项目时间中安排 Python 模型 API 结构化结果练习
- **2026-10-25：**根据真实投入、解题、代码复写和项目结果更新下一月计划

每周 24 小时默认分配：

| 学习线 | 每周时间 |
|---|---:|
| 数学 | 8 小时 |
| 408 笔试 | 5 小时 |
| Java 算法 | 2 小时 |
| 英语 | 4 小时 |
| Java／AI 应用项目 | 4 小时 |
| 周复盘 | 1 小时 |

408 笔试、Java 算法与项目分别记时，不重复计入。模型 API、RAG、工具调用和评测都从项目 4 小时内重新分配，不增加周总量。连续两周超负荷时先减少项目功能和额外视频；数学或 408 首轮落后两周以上时，暂停增加 AI 功能。

## 长期节点

- **2026 年 11 月底：**Java 与算法继续；每两周一次 Python 模型 API／结构化结果练习，并开始用 AI 辅助测试和排错
- **2027 年 2 月底：**完成 SQL、HTTP、数据库与基础后端，项目接入一个简单模型功能
- **2027 年 4 月底：**完成基础预约业务与带引用的文档问答，理解 Embedding 和 RAG
- **2027 年 6 月底：**数学与 408 首轮结束；加入查询／预约工具调用，建立评测集，项目可演示并写进简历
- **2027 年 7—8 月：**考研强化为主，项目只修错、跑回归评测和维护文档
- **2027 年 9 月起：**主要精力转向初试；秋招、笔试和面试放进固定时间窗口
- **初试后：**增加 Java 机考与专业面试训练，并按考试结果继续实习或春招

AI 辅助编程遵循两条边界：核心算法先独立完成，再让 AI 审查；项目代码可以让 AI 协助生成，但所有改动都必须自行检查、运行测试并能够解释。当前不同时学习大模型训练、微调和论文研究。

目前按数学一、英语一、408、政治准备。最终专业、考试科目、统考计划与培养信息必须以 2027 年秋发布的 2028 招生目录为准。

任务包带版本号。访问页面或导入旧备份时，会替换对应周的预置任务，同时保留自定义任务、每日记录、复盘和可匹配的完成状态；被替换的旧预置任务保存在 planHistory 中。

周任务位于 src/data/weeklyPlan.js，整体路线位于 src/data/roadmap.js。变更预置任务时需更新 planWindow.revision。

## 本地开发

~~~bash
pnpm install
pnpm dev
~~~

访问 http://localhost:5173/learn/。生产构建：

~~~bash
pnpm build
pnpm preview
~~~

数据保存在当前浏览器 localStorage 中。建议每周在“周复盘”页导出一次 JSON 备份。

## 与 AI 一起学习

1. 在“今日”选择要讨论的日期，点击“复制本周任务给 AI”。
2. 预览默认包含任务、自定义任务和打卡／专注统计，不含个人笔记。
3. 粘贴到新的每周学习会话，并补充今天可用时间、当前进度和具体卡点。

网站不会自动上传私人记录，也不提供跨设备云同步。
