# KIXU LEARN

一个部署在 `kixuxs.vip/learn` 的个人职业成长与每日打卡应用。它不是单一技术课程表，而是把工程能力、作品与实习、方向实验、学业选择和关键决策点放在同一条路线上。

## 功能

- 最近一个月的详细周任务：包含执行步骤、预计用时、完成标准和官方学习链接
- 周任务与每日打卡分离；每天保留专注计时、学习笔记和打卡记录
- 支持补充自定义周任务，详细任务包按月结合真实进度更新
- “复制本周任务给 AI”：预览所选周的完整任务、学习链接和进度，个人笔记与复盘可选；仅本地生成，不自动调用 AI
- 15 / 25 / 45 / 60 分钟专注计时，记入周投入
- 2026.08—2028.06 的职业路线图和四个证据决策点
- 游戏客户端、后端 / AI 应用、AI Infra / CANN、科研读研、公务员现实调查五类限时实验
- 周复盘、JSON 导入导出、离线访问和手机端布局

## 本地开发

```bash
pnpm install
pnpm dev
```

访问 `http://localhost:5173/learn/`。生产构建：

```bash
pnpm build
pnpm preview
```

应用数据默认保存在当前浏览器 `localStorage` 中。上线后建议每周在「周复盘」页导出一次 JSON 备份。

## 当前任务包

从 **2026-08-31** 重新开始第 1 周，六周任务覆盖至 **2026-10-11**，建议 **2026-09-28** 根据实际完成情况更新下一月计划。第一周约 7 小时，不补赶之前未完成的进度。

任务包带版本号：访问页面或导入旧备份时，会更新对应周的预置任务，保留同一任务的完成状态、自定义任务以及所有每日记录和复盘。被替换的旧预置任务留在备份数据的 `planHistory` 中，起点前的周记录不变。

当前路线：先用 Unity 完成小作品，再根据验收和目标岗位评估 UE 蓝图 + C++；11 月是预计窗口，不强制切换、不同时学习两套引擎。比赛选做，保留 Git、算法、系统基础、学业与实习，以及限时的其他职业方向验证。

周任务文本在 `src/data/weeklyPlan.js`，整体路线在 `src/data/roadmap.js`。变更预置任务内容时需同步更新 `planWindow.revision`，以便旧浏览器收到新说明。

## 与 AI 一起学习

1. 在「今日」选择想讨论的日期，点击「复制本周任务给 AI」。导出的是**当前查看日期所属的周**，不是固定今天。
2. 预览中默认包含任务、自定义任务和打卡/专注统计，不含个人笔记。需要讨论卡点时再勾选包含本周笔记与已保存的周复盘。
3. 点击「复制到剪贴板」，粘贴给常用 AI，并补充当前卡点、可用时间、Editor 版本或报错。若浏览器拒绝自动复制，使用「全选文本」手动复制。

网站不会把记录自动发给 AI；AI 也不能仅凭网址读取浏览器内的私人打卡数据。切换设备/浏览器仍需 JSON 备份导入，不提供云同步。

验证命令：`node --test src/data/weeklyPlan.test.js src/utils/weeklyAiContext.test.js`、`pnpm lint`、`pnpm build`。
