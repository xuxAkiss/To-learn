# KIXU LEARN

一个部署在 GitHub Pages 的个人考研周计划、科目诊断与每日打卡应用。当前目标是参加 2027 年底初试，暂以复旦大学计算与智能创新学院相关专硕为冲刺方向。

线上地址：<https://xuxakiss.github.io/To-learn/>

## 功能

- 近期四周详细任务，包含执行步骤、预计用时、完成标准和学习入口
- 周任务与每日打卡分离；每天保留专注计时、学习笔记和打卡记录
- 支持补充自定义周任务，任务包按月根据真实完成情况更新
- “复制本周任务给 AI”：预览所选周任务、链接与进度，个人笔记和复盘默认不包含
- 15 / 25 / 45 / 60 分钟专注计时与周投入统计
- 2026.09—2027.12 的数学、408、英语/政治、复试/报考路线图
- 数学、408、英语、C++和时间负荷五类诊断卡
- 周复盘、JSON 导入导出、离线访问和手机端布局

## 当前任务包

- **2026-09-21—09-27：**路线切换、资料固定和基础小测，约 4 小时
- **2026-09-28—10-25：**连续四周基础任务，每周约 22 小时
- **2026-10-25：**根据真实投入、错题重做、数据结构小测和英语阅读数据更新下一阶段计划

每周 22 小时的默认分配为：数学 9 小时、408 8 小时（含约 2 小时 C++）、英语 4 小时、复盘 1 小时。政治计划在 2027 年 7 月左右系统开始。

任务包带版本号。访问页面或导入旧备份时，会替换对应周的预置任务，同时保留自定义任务、每日记录、复盘和既有完成状态；被替换的旧预置任务保存在 `planHistory` 中。

周任务位于 `src/data/weeklyPlan.js`，整体路线位于 `src/data/roadmap.js`。变更预置任务时需更新 `planWindow.revision`。

## 本地开发

```bash
pnpm install
pnpm dev
```

访问 `http://localhost:5173/learn/`。生产构建：

```bash
pnpm build
pnpm preview
```

数据保存在当前浏览器 `localStorage` 中。建议每周在“周复盘”页导出一次 JSON 备份。

## 与 AI 一起学习

1. 在“今日”选择要讨论的日期，点击“复制本周任务给 AI”。
2. 预览默认包含任务、自定义任务和打卡/专注统计，不含个人笔记。
3. 粘贴到新的每周学习会话，并补充今天可用时间、当前进度和具体卡点。

网站不会自动上传私人记录，也不提供跨设备云同步。

## 验证与部署
